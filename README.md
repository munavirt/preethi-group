# Preethi Group

Welcome to the Preethi Group corporate website repository.

## Overview

This project is a modern, performance-optimized Next.js application built with React, Tailwind CSS, and Framer Motion. It serves as the digital presence for the Preethi Group, showcasing its history, businesses, and leadership.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
